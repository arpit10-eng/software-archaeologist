# Contributing to Software Archaeologist

Thank you for your interest in contributing to Software Archaeologist.

Software Archaeologist is an open-source repository intelligence platform
designed to analyze GitHub repositories and provide insights into their
architecture, dependencies, code quality, security, complexity, and overall
health.

## How to Contribute

### 1. Fork the Repository

Create your own fork of the repository on GitHub.

### 2. Clone Your Fork

```bash
git clone https://github.com/arpit10-eng/software-archaeologist.git
cd software-archaeologist
